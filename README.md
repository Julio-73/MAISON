# 🖤 MAISON — Haute Couture Landing Page

> Una landing page premium para una maison de haute couture ficticia. Diseño editorial, animaciones cinematográficas, video en hero, scroll fluido con Lenis, mini-cart funcional y 17 secciones modulares.

## ✨ Características

- 🎬 Hero cinemático con video loop UHD y control de audio
- 🎭 Loader con barra de progreso animada
- 🍯 Smooth scroll con Lenis (curva custom)
- 📊 LiveStats con contadores animados y hora en vivo de París
- 📖 Process Timeline del hilo a la pasarela
- 💰 Lookbook con mini-cart funcional y 4 productos
- 🌍 Showrooms internacionales (París, Milano, Tokyo, NY)
- 🪙 Newsletter "Cercle Privé" con lead magnet editorial
- 🌍 Selector de idioma (FR/EN/IT/ES/JP)
- 🖱️ Cursor magnético con mix-blend-mode
- 📱 100% responsive mobile-first
- ⚡ Build optimizado: 137 KB gzipped

---

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/Julio-73/MAISON.git
cd MAISON

# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev
# → http://localhost:5173

# Build de producción
npm run build
npm run preview
```

---

## 🎨 Stack técnico

- React 18 + TypeScript 5
- Vite 5 (build ultrarrápido)
- Tailwind CSS 4 (styling utility-first)
- Framer Motion 11 (animaciones declarativas)
- Lenis (smooth scroll)
- Lucide React (iconos)
